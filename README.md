# 루틴핏 v1.0.1 — 홈 화면 설치 버전

루틴핏 v1.0.1 — 갤럭시 홈 화면에 앱 설치하기

★ 준비사항: 루틴핏을 HTTPS 사이트로 먼저 공개해야 합니다. 내려받은 HTML 파일 자체는 '앱 설치' 기능이 작동하지 않습니다.

1) 무료 공개 (GitHub Pages, 처음 한 번만 설정)
  ① GitHub.com에 무료 계정을 만들고 공개(Public) 저장소 routinefit 를 생성합니다.
  ② 웹앱 ZIP 압축을 해제하고 index.html, app.js, style.css, manifest.webmanifest, sw.js, assets 폴더 등을 저장소 최상위에 업로드합니다.
  ③ 저장소 Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save를 선택합니다.
  ④ Pages에서 안내하는 https://계정.github.io/routinefit/ 주소를 확인합니다.

2) 갤럭시 홈 화면에 설치 (처음 한 번)
  ① 위 HTTPS 주소를 갤럭시 Chrome에서 엽니다. 카카오톡·ChatGPT 내부 브라우저가 아닌 Chrome 앱으로 여세요.
  ② 사이트의 '설치하기' 버튼을 누르고, 설치 화면이 나오면 확인합니다.
  ③ 설치 창이 나오지 않을 경우 Chrome 오른쪽 상단 점 3개(⋮) > '홈 화면에 추가' 또는 '앱 설치' > 설치를 탭합니다.
  ④ 홈 화면 또는 앱 서랍의 초록색 덤벨 아이콘 '루틴핏'을 누르면 바로 실행됩니다.

  Samsung Internet 사용 시: 페이지 열기 > 아래 메뉴(≡) > '현재 페이지 추가/홈 화면에 추가' > 홈 화면.

3) 홈 화면 실행 이후
  - 앱 아이콘을 누르면 브라우저 주소창 없이 앱 전용 화면으로 실행됩니다 (정상 설치형 PWA 기준).
  - 최초 방문에서 모든 파일이 캐시되면 인터넷 없이도 열 수 있습니다.
  - 루틴 / 세트 / 체중 데이터는 기기·브라우저별 로컬 저장입니다. 삭제·휴대폰 교체 전에 앱 설정 > 백업 저장으로 JSON 파일을 보관하세요.
  - 기존 v1.0의 데이터 저장 키(routinefit_v1_store)를 유지하므로 동일한 주소·브라우저에서 업데이트하는 경우 기존 기록을 계속 사용합니다. 주소가 달라지면 백업/복원이 필요합니다.

참고: 안드로이드 앱스토어용 APK는 아직 생성되지 않았습니다. ZIP은 설치 APK가 아니라 웹 배포 패키지입니다.
