루틴핏 개인정보처리방침

시행일: 2026년 10월 28일 · 문의: nanami1288@naver.com

루틴핏(RoutineFit)은 운동 루틴·운동 수행 기록·체중·식단을 관리하는 애플리케이션 및 웹 서비스를 제공합니다. 이 방침은 현재 출시 준비 중인 로컬 저장형 앱의 실제 기능을 기준으로 작성하였습니다. 향후 계정·클라우드·커뮤니티·광고 추적 기능이 생길 경우 실제 도입 전에 별도 고지와 적절한 처리 근거·동의 절차를 마련합니다.

1. 개인정보 처리 목적 및 항목

  • 기기 내부 기능 사용: 요일별 루틴, 운동 종목, 중량·횟수·세트·휴식시간·운동 이력, 체중·체성분·목표 체중, 식단·칼로리 및 사용자 입력 종목·영상/이미지 주소를 기기 내부에 저장해 앱의 기록·통계·복원 기능에 사용합니다. 이러한 내용은 사용자가 입력·관리하며, 현 버전에서 루틴핏 운영자 서버로 자동 업로드되지 않습니다.
  • 문의 응대: 사용자가 이메일로 문의하면 이메일 주소와 문의 내용 및 답변 기록을 처리할 수 있습니다. 이용자가 선택하지 않은 운동·건강 기록을 이메일로 요구하지 않습니다.
  • 회원정보: 현재 회원가입·서버 동기화 기능은 없습니다.

2. 저장 위치와 보유 기간

운동·체중·식단 데이터는 앱의 로컬 저장소(localStorage 및 IndexedDB 등)에 보관되며 이용자가 앱에서 삭제하거나 앱 저장 데이터를 삭제하기 전까지 해당 기기에 남을 수 있습니다. 운영자는 해당 로컬 저장소에 직접 접근하거나 삭제·복구할 수 없습니다. JSON 백업 파일은 이용자가 선택한 기기의 파일 저장소에 별도로 보관되므로, 앱 데이터 삭제와 별개로 직접 관리·삭제해야 합니다.

이메일 문의 내용은 문의 답변·분쟁 대응에 필요한 범위에서 처리하고 목적 달성 후 안전하게 삭제합니다. 법령상 보존 의무가 있는 기록은 해당 법령에서 정한 기간 보관할 수 있습니다. 문의 메일의 실제 보관 체계·기간은 운영자가 확정해야 하며, 장기간 보관 정책이 있다면 이 조항을 구체화해야 합니다.

3. 외부 서비스에 연결될 때의 정보

  • 이용자가 운동 영상 버튼을 누르면 운동명 등 검색어와 함께 YouTube 웹사이트가 열릴 수 있습니다. 사용자 지정 동영상 URL 역시 외부 YouTube로 연결될 수 있습니다.
  • 이용자가 영양성분 참고 링크를 누르면 식품안전나라 등 별도 사이트를 열 수 있습니다.
  • 사용자가 직접 입력한 외부 이미지 URL을 앱에 연결하는 경우 이미지 제공 서버에 네트워크 요청이 발생할 수 있습니다.

이때 외부 서비스 사업자는 접속 IP, 브라우저·기기 정보, 쿠키 등 데이터를 각자의 정책에 따라 처리할 수 있습니다. 루틴핏 운영자가 해당 외부 사업자의 정보 처리 전부를 통제하지는 않습니다. 웹앱의 GitHub Pages 등 호스팅 사업자도 통상적인 접속 정보를 처리할 수 있습니다. 외부 링크는 이용자의 선택으로 열립니다.

4. 제3자 제공·처리위탁·국외 이전

현 버전에서는 운영자가 운동·체중·식단 데이터를 서버로 수집해 제3자에 제공하거나 처리위탁하지 않습니다. 이용자가 외부 링크를 선택하는 것과 운영자가 해당 기록을 제3자에게 제공하는 것은 구분됩니다. 추후 회원관리, 클라우드 저장, 사진 공유, 광고 SDK 또는 분석 SDK가 도입되면, 실제 업체·국가·항목·목적·보유기간과 처리근거를 확인한 후 방침을 개정합니다.

5. 광고 및 자동 수집 장치

현 버전의 홈 화면에는 세 개의 '광고 문의' 자리만 존재하며, 실제 광고 네트워크·행동 분석 SDK·개인 맞춤 광고 추적 기능이 포함되어 있지 않습니다. 광고 서비스를 도입하는 경우 광고 표시와 데이터 처리 내용을 별도 공지하고 관련 동의가 필요한 경우 선택권을 제공합니다. 외부 웹사이트의 쿠키 등은 해당 서비스 정책의 적용을 받습니다.

6. 이용자 권리 및 데이터 삭제

이용자는 앱에서 기록을 수정·삭제하거나 전체 초기화를 할 수 있고, JSON 파일을 내보내고 가져올 수 있습니다. 개인정보 관련 문의는 nanami1288@naver.com로 접수할 수 있습니다. 운영자가 보유하지 않은 기기 내부 정보는 직접 열람·수정할 수 없으므로, 이용자 기기에서 관리해야 합니다. 이메일 문의 정보에 관한 접근·정정·삭제 요청은 본인 확인 후 관련 법령에 따라 처리합니다.

7. 안전조치 및 접근권한

앱에서는 JavaScript 기반 로컬 저장을 이용하며 Android 앱에는 외부 링크 이용에 필요한 인터넷 권한이 포함됩니다. 파일 백업·복원 시 이용자가 시스템 파일 선택 화면에서 파일과 저장 위치를 지정합니다. 현 버전의 AndroidManifest에는 위치·카메라·마이크·연락처 권한이 포함돼 있지 않습니다. 사용자의 기기 잠금과 파일 백업 안전성은 이용 환경에 영향을 받습니다.

8. 아동·건강정보 및 공개 범위

현 버전은 운동 데이터를 다른 이용자에게 공개하는 기능을 제공하지 않습니다. 향후 회원가입·랭킹·전후 사진 공유를 도입하면 기본 공개값을 비공개로 설정하고 건강 관련 정보, 아동 정보 및 사진 공개에 대해 기능별로 추가 고지·적법한 동의·연령 확인 등 필요한 조치를 마련합니다.

9. 운동·칼로리 정보에 관한 고지

1RM, 운동 소모 칼로리, 섭취·소모 칼로리 비교 등의 수치는 참고용 추정값이며 의학적 진단·치료 또는 전문적인 운동·영양 처방을 대신하지 않습니다.
